Object and Object manupulation -->
An object in javascript is a collection of properties stored as key-value pairs. it is used to store data about somting.

let student = {
    name: "Aman",
    age: 20,
    course: "computer science",
    marks: 85
}
Here name,age,course and marks are properties and their corresponding values are "aman",20,"computer science" and 85.

console.log(student.name);
